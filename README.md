# میزون (سایت یکپارچه)

نسخهٔ ادغام‌شدهٔ پروژه‌های `mizoon` و `shakhsiat`.

## امکانات

- آزمون رایگان تیپ ۱۶گانه (مهمان‌محور)
- دانشنامه تیپ‌ها با paywall فصل‌های شغلی
- آزمون‌های تخصصی پس از ورود (شخصیت، هیجان، روابط ۳۶۰، رشد)
- گزارش‌ها، دعوت اطرافیان، اجتماعی، اعلان‌ها
- ورود با OTP موبایل (معماری آمادهٔ SMS)
- پرداخت زرین‌پال (تأیید سمت سرور)

## پیش‌نیاز

- Node.js 20+
- npm

## راه‌اندازی محلی

```bash
cd site
cp .env.example .env
npm install
npm run db:setup
npm run dev
```

آدرس: [http://localhost:3000](http://localhost:3000)

### حالت توسعه (بدون کلید خارجی)

| سرویس | رفتار |
|--------|--------|
| SMS | کد OTP در کنسول سرور + فیلد `devCode` در پاسخ API / صفحه ورود |
| پرداخت | درگاه شبیه‌سازی؛ پس از کلیک، callback موفق و آنلاک |

### تست سریع

1. باز کردن `/` → «آزمون رایگان تیپ شخصیت»
2. پاسخ به سؤالات → صفحه نتیجه
3. `/auth/login` با شماره `09123456789` → کد از کنسول/صفحه
4. `/dashboard` → آزمون‌های تخصصی
5. `/pricing` → خرید آزمایشی (DEV)

## دیتابیس

- **محلی:** SQLite (`DATABASE_URL="file:./dev.db"`)
- **پروداکشن پیشنهادی:** PostgreSQL — در `prisma/schema.prisma` مقدار `provider` را به `postgresql` تغییر دهید و `DATABASE_URL` را تنظیم کنید.

```bash
npm run db:generate
npm run db:push      # یا db:migrate
npm run db:seed
```

## اسکریپت‌ها

| دستور | کار |
|--------|-----|
| `npm run dev` | توسعه |
| `npm run build` / `npm start` | تولید |
| `npm run db:setup` | push + seed |

## متغیرهای محیطی

همه در `.env.example` مستند شده‌اند.

## امنیت

- OTP شش‌رقمی با `crypto.randomInt` و ذخیرهٔ **hash** (نه متن ساده)
- محدودیت ارسال و تلاش تأیید OTP
- تأیید پرداخت فقط سمت سرور؛ `DEV-*` فقط وقتی merchant خالی است
- فصل‌های `careers` / `workplace` بدون آنلاک نمایش داده نمی‌شوند
